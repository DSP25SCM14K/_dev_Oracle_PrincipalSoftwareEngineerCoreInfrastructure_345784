# Dev Kumar — Distributed Systems and Core Cloud Infrastructure Portfolio

A responsive engineering portfolio for distributed systems and cloud infrastructure. The animated data-plane diagram, reliability engineering loop, complete experience history, and project collection reflect this resume's emphasis on fault tolerance, quorum replication, automatic failover, safe operations, and high-throughput data paths.

Open `index.html` directly or serve this folder with a static web server. GitHub Pages publishes the repository root from the `main` branch.

- `index.html` — portfolio content and infrastructure architecture diagram
- `styles.css` — responsive layout and animation
- `script.js` — animated background, rotating focus text, reveals, and project search
- `.nojekyll` — keep static site files available to GitHub Pages
